# SchoolShield · Учитель · Linux Mint

Фильтр материалов 18+ (порно, эротика) и «Центр учителя» для компьютеров учителей на Linux Mint (Cinnamon, X11).
Всё остальное работает как обычно: программы устанавливаются, терминал, флешки, файловый менеджер, любые браузеры.

Автор: Латипов С.А. Лицензия MIT. Только стандартная библиотека Python, без сторонних модулей.

## Установка

Скачайте `schoolshield-teacher_<версия>_all.deb` со страницы [релизов](https://github.com/Scrymez/SchoolShield/releases) и установите:

```bash
sudo apt install ./schoolshield-teacher_2.2.0_all.deb
```

Фильтр включается сразу при установке. Откройте **«Центр учителя»** в меню приложений (раздел «Образование»).
После установки выйдите из сеанса и войдите снова: так стартует охрана окон, а браузеры подхватят политики.

Проверено на Linux Mint 21.x и 22.x (Cinnamon). Нужны пакеты `python3-gi` и `gir1.2-webkit2-4.1` (или `-4.0`), `wmctrl`, `libnotify-bin`, `policykit-1`: `apt` поставит их сам.

## Что делает фильтр 18+

| Слой | Что именно | Нужен root |
|------|-----------|------------|
| Семейный DNS | AdGuard Family (по умолчанию), Cloudflare Family, CleanBrowsing, Яндекс. `systemd-resolved` + скрипт NetworkManager, который заменяет DNS при каждом подключении к сети. VPN-интерфейсы (`tun*`, `wg*`, `tailscale*`) не трогаются | да, при установке |
| Браузеры | SafeSearch (Google, Bing) и около 900 самых посещаемых сайтов 18+ в политиках Chrome, Chromium, Edge, Brave, Vivaldi, Firefox. Чужие политики Firefox сохраняются и возвращаются при отключении | да |
| `/etc/hosts` | Сотни крупных сайтов 18+ (и `www.`) направляются на `0.0.0.0` | да |
| Охрана окон | Каждые 0,7 с проверяет заголовки окон (`wmctrl`). Порно-слова закрывают окно; «p o r n o», «p0rn», «пoрнo» с латинской «o» тоже. Слова «секс», «nude», «эротика» **не** закрывают окно: урок биологии или искусства должен остаться | нет, работает в сеансе |
| ИИ-фильтр экрана | Необязательно. Yahoo open_nsfw (BSD-2) через ONNX Runtime на процессоре, ничего не отправляется в сеть. Закрывает активное окно при нескольких кадрах подряд выше порога | установка: да |

Включить ИИ-фильтр экрана: «Центр учителя» → «Защита 18+» → «Установить ИИ-фильтр экрана» (нужен интернет, скачивается onnxruntime и модель 23 МБ с проверкой контрольной суммы), затем отметить «ИИ-фильтр экрана».

## Центр учителя

Один экран с большими кнопками простыми словами (для тех, кому трудно с Linux): **Файлы и флешка**, **Интернет и Wi-Fi**, Документы, Фото и видео, Программы, **Настройки**, **Помощь**, Защита 18+. Цвета сайта интеллектшкола.рф, светлая тема по умолчанию, крупный текст (кнопка «A++» вверху: обычный, крупный, очень крупный).

* **Файлы и флешка.** Места слева (рабочий стол, документы, загрузки, диски). Флешка появляется сама, при нажатии подключается (`udisksctl`), значок ⏏ извлекает безопасно. Файлы **перетаскиваются мышью** (в папку, на «Место», на флешку; из диспетчера файлов Nemo тоже) или кнопками «Копировать / Вырезать / Вставить». «На флешку» и «С флешки в Документы» одним нажатием. Копирование идёт в фоне с полоской хода и отменой; занятое имя получает номер (2); удаление в корзину (`gio trash`), с флешки насовсем после предупреждения. Системные папки (`/`, `/home`, ваша домашняя) удалить и переименовать нельзя.
* **Интернет и Wi-Fi.** Сети рядом крупным списком, «Подключиться» (`nmcli`), пароль в большом окне с глазком, проверка «работает ли интернет» (NetworkManager).
* **Настройки.** Громкость, яркость (`brightnessctl`, если установлен), **проектор** («Повторить», «Расширить», «Только проектор», «Только этот экран», через `xrandr`), размер текста, тема, принтеры, Bluetooth, мышь, клавиатура, дата и время, «Параметры системы», установка программ, обновления, питание.
* **Помощь.** Девять коротких ответов шагами.

Программы Windows через Wine, Bottles или Lutris попадают в «Программы» сами, как только у них появляется ярлык в меню.

Окно работает на GTK и WebKit. Если их нет, Центр открывается во вкладке обычного браузера: `schoolshield-teacher center --browser`. Для регулировки яркости установите `brightnessctl` (`sudo apt install brightnessctl`).

## Команды

```bash
schoolshield-teacher center            # Центр учителя
schoolshield-teacher status            # что сейчас включено
sudo schoolshield-teacher apply        # включить или применить заново
sudo schoolshield-teacher remove       # отключить: DNS, политики и /etc/hosts возвращаются как были
schoolshield-teacher update --install  # обновление из GitHub: проверка подписи автора, затем установка
```

Настройки администратора: `/etc/schoolshield/config.json` (`dns`, `hosts_block`, `ai.enabled`, `ai.threshold`), свои добавки: `/etc/schoolshield/blocklist-extra.txt` и `badwords-extra.txt` (удобнее через «Центр учителя» → «Защита 18+» → «Мои добавки»).

## Безопасность

* Центр учителя слушает только `127.0.0.1`, каждый запрос требует случайный токен сеанса; проверяются заголовки `Host` и `Origin`.
* Всё, что меняет систему, выполняет `pkexec`: система спрашивает пароль администратора. Центр не получает root.
* Обновление ставится только после проверки подписи RSA-SHA256 (тот же ключ, что у Windows-версии); проверка повторяется от root над копией файла.
* Персональные данные не собираются и никуда не отправляются. Журнал охраны лежит в `~/.local/state/schoolshield/guard.log` и содержит заголовки закрытых окон: уберите его, если это нежелательно.

## Ограничения (честно)

* Сеанс **Wayland**: чужие окна недоступны, охрана окон и ИИ-фильтр экрана не работают. DNS, политики браузеров и `/etc/hosts` действуют. В Linux Mint по умолчанию X11.
* Браузеры из Snap и Flatpak читают политики из своих песочниц: для них действует DNS-фильтр, но не политики.
* В политики Chrome и Edge помещается около 900 сайтов; остальное закрывают DNS-фильтр и охрана.
* Сайты, зеркала которых заданы шаблоном `имя.*`, закрывают DNS-фильтр и охрана окон, но не `/etc/hosts`.
* Человек с правами администратора может отключить фильтр: это защита для учителя, а не от учителя.

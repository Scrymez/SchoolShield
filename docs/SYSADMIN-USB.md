# Сисадмин-флешка: стек программ и операционных систем для школы

Автор проекта: Латипов С.А. Дата: 2 ноября 2026. Для школьного системного администратора: одна загрузочная флешка (или внешний SSD), с которой можно установить любую нужную ОС, починить, склонировать, проверить и безопасно списать компьютер учителя или ученика.
Версии дистрибутивов и условия лицензий меняются: перед закупкой и копированием сверяйте сайты производителей.

## 1. Принцип устройства

* **Ventoy** (лицензия GPL-3.0, открытый исходный код): флешка делится на служебный раздел и раздел с данными. Образы `.iso`, `.wim`, `.img`, `.vhd(x)` просто копируются файлами в папки, при загрузке появляется меню. Не нужно перезаписывать флешку под каждый образ. Поддерживается Secure Boot (при первой загрузке на ПК с включённым Secure Boot нужно один раз подтвердить ключ Ventoy в MOK).
* **Две флешки лучше одной.**
  * **«Белая» (инструменты, только чтение).** Образы ОС, спасательные диски, драйверы, утилиты. Лучше с физическим переключателем защиты от записи: на заражённом ПК флешка не станет источником заражения.
  * **«Чёрная» (рабочая).** Образы дисков (Clonezilla), журналы, отчёты, выгрузки. Всё, где могут оказаться персональные данные, хранится **только в зашифрованном виде** (LUKS или VeraCrypt) и числится в журнале учёта носителей.
* **Объём:** минимум 128 ГБ, удобно 256–512 ГБ (быстрый USB 3.2 или портативный SSD): образы Windows и Mint занимают 5–8 ГБ каждый.
* **Никаких секретов на «белой» флешке:** пароли, ключи подписи обновлений, коды администратора и адреса серверов не хранятся на ней вообще (они лежат в менеджере паролей и офлайн-хранилище). Это правило проекта: инфраструктурные данные не попадают в Git и на общие носители.
* **Проверка образов:** каждый `.iso` сверяется с опубликованным хэшем (`sha256sum`) и подписью (GPG), пока лежит на флешке: файл `SHA256SUMS` рядом с образом. Ventoy позволяет проверить сумму прямо в меню.

├── Windows-инструменты/      портативные программы (раздел 4)
├── Linux-инструменты/        скрипты, .deb, AppImage (раздел 5)
├── Драйверы/                 по производителям и моделям (Lenovo, HP, Dell, Acer, ASUS)

## 2. Какие операционные системы держать на флешке

### 2.1. Для работы и учёбы: учителям и ученикам

| ОС | Лицензия | Для кого и зачем | Замечания |
|----|----------|------------------|-----------|
| **Linux Mint 22.x Cinnamon** (база Ubuntu 24.04, поддержка до 2029) | GPL и др. | **Главная для компьютеров учителей**: привычный рабочий стол, как у Windows; редакция SchoolShield «Учитель» ставится одним пакетом | Образ ~3 ГБ; нужен Secure Boot ключ Ubuntu (работает штатно) |
| **LMDE 7** (Mint на базе Debian 13) | GPL и др. | Если нужна независимость от Ubuntu | Установщик отличается от Mint; проверять сроки выпуска |
| **Ubuntu 24.04 LTS** / **Kubuntu** (KDE) | GPL и др. (Canonical, торговая марка) | Для тех, кто предпочитает KDE; широкая поддержка оборудования | Snap по умолчанию |
| **Debian 13 «trixie»** (netinst и live) | GPL и др. | Основа будущей ОС SchoolShield; серверы | Прошивки в отдельном образе `firmware` |
| **Debian Edu (Skolelinux)** | GPL и др. | Готовое школьное решение: сервер (LDAP, Kerberos, Samba), рабочие места, **LTSP** для бездисковых ПК | Свой подход к устройству сети |
| **Edubuntu** | GPL и др. | Ученические ПК: образовательные программы в комплекте | Официальная разновидность Ubuntu |
| **Альт Образование / Альт Рабочая станция** | свободные компоненты, смотрите условия на basealt.ru | Школьные компьютеры, есть требования по импортозамещению; у линейки есть сертифицированные редакции (проверять в реестре ФСТЭК) | Лицензионные условия и сертификаты проверять у производителя |
| **Astra Linux Common Edition**, **РЕД ОС** | условия производителя | Если школа обязана использовать сертифицированную ОС | Условия бесплатного использования проверять; образ часто требует регистрации |
| **Windows 11 Pro/Education** и **Windows 10 Enterprise LTSC / IoT LTSC** | Платные (лицензия школы) | Рабочие места, где нужны программы только для Windows. Поддержка обычного Windows 10 закончилась **14.10.2025**; LTSC живёт дольше (сроки проверять) | Скачивать **только официальные** образы Microsoft; без активаторов |
| **Zorin OS Core** | GPL и др. | Запасной вариант «как Windows» | Платные редакции есть, но Core бесплатна |

Не рекомендуется для школьных данных: облачные ОС с обязательной учётной записью (например, ChromeOS Flex), потому что данные уходят за пределы школы; для ПД это нарушает принцип локализации и минимизации.

## 6. Типовые задачи (шпаргалки)

1. **Компьютер учителя на Linux Mint.** Загрузка с флешки → «Linux Mint 22 Cinnamon» → Установить (шифрование диска включить на ноутбуках) → после перезагрузки: `sudo apt install ./schoolshield-teacher_*_all.deb` → выйти и войти. Фильтр 18+ включается автоматически; Центр учителя в меню «Образование».
2. **Компьютер учителя на Windows.** Установить Windows (автоответ через `auto_install` и `unattend.xml`) → `SchoolShield-Setup-*.exe /S /edition=teacher` → фильтр 18+ включается сам. Без запретов на установку, диспетчер задач, USB.
3. **Ученический компьютер на Windows.** Windows + `SchoolShield-Setup-*.exe /S` → затем «Первый запуск» мастера в панели администратора (код, учётная запись ученика, оболочка).
4. **Клонирование.** Эталонный ПК → Clonezilla → образ на сетевой диск или «чёрную» флешку (шифрованную) → развернуть на остальные; после клонирования сменить имя ПК и повторно применить защиту.
5. **Диагностика «тормозит/зависает».** MemTest86+ (2 прохода) → `smartctl -a` / CrystalDiskInfo → температура, пыль, питание → замена узла.
6. **Забыли код администратора SchoolShield (Windows).** Порядок из документации проекта (раздел «Аварийное восстановление»): физический доступ, загрузка в WinPE или другой администратор, аварийный выключатель в папке данных. Действие журналируется.
7. **Списание или передача ПК.** ShredOS (nwipe) или стирание средствами накопителя (ATA Secure Erase, NVMe sanitize/format, крипто-стирание для самошифрующихся дисков) → акт списания с номером носителя.
8. **Проверка заражения.** Антивирусный live-диск → Autoruns/ProcMon (Windows) → переустановка из эталонного образа, если есть сомнения.

## 7. Гигиена флешки и персональные данные

* Флешки с ПД **шифруются** и вносятся в журнал учёта носителей (кто, когда, зачем взял). Журнал и порядок стирания входят в организационные меры по защите ПД (152-ФЗ, ст. 19; состав мер для УЗ-3 и УЗ-4 в Постановлении №1119 и Приказе ФСТЭК №21).
* Образ эталонного ПК не должен содержать личных файлов учеников и учителей: перед клонированием чистим профили.
* На «белой» флешке нет паролей и ключей; на «чёрной» шифрованный раздел.
* Любой «активатор», «кряк» или сборка с неясным происхождением на флешку не попадает: это и юридический риск, и канал заражения.
* Раз в квартал: обновить образы (Mint, Ubuntu, Debian, SystemRescue, Clonezilla), проверить хэши, обновить Ventoy (обновление не стирает данные), проверить `.sig` пакетов SchoolShield, убрать устаревшие образы.

## 8. Минимальный стартовый комплект (если нужно начать сегодня)

1. Ventoy на флешку 128 ГБ.
2. Linux Mint 22 Cinnamon, Windows 11 (официальный образ), SystemRescue, Clonezilla, MemTest86+, ShredOS.
3. Rufus, 7-Zip, Sysinternals, CrystalDiskInfo, Wireshark, RustDesk.
4. `SchoolShield-Setup-*.exe` с `.sig` и `schoolshield-teacher_*_all.deb` с `.sig` из релиза.
5. Драйверы Wi-Fi и сети для ваших моделей.

# SchoolShield

Защита школьного компьютера с **Windows 10**. Ученик видит только лаунчер вместо рабочего стола: разделы «Программы», «Документы», «Фото, видео, музыка», «Мои файлы», «Интернет». Установить программу, скачать «установщик», открыть неприемлемый сайт или картинку, зайти в проводник и параметры Windows нельзя. Администратор входит скрытой комбинацией клавиш и кодом.

Автор: **Латипов С.А.** · Лицензия: MIT · Сайт: https://github.com/Scrymez/SchoolShield

> **Статус.** Версия 2.3. Перед внедрением на всех компьютерах проверьте её на одном ПК или в виртуальной машине (см. «Быстрый старт»). Программа писалась и проверялась на macOS (логика, политики, сборка); при сбоях на реальном ПК присылайте журнал `C:\ProgramData\SchoolShield\logs\*.log`.

## Редакции

| | Ученик | Учитель |
|---|---|---|
| Для кого | школьный компьютер | компьютер учителя |
| Windows | лаунчер вместо рабочего стола, запрет установки, все защиты ниже | **обычная Windows**, лаунчер «Центр учителя» как обычное окно; закрыт только материал 18+ |
| Linux Mint | не нужна (используйте Windows-редакцию) | **пакет `.deb`**: Центр учителя, фильтр 18+, подробности в [`linux/README.md`](linux/README.md) |
| Что фильтруется | всё перечисленное в «Возможностях» | **только 18+ (порно, эротика)**: списки сайтов, семейный DNS, SafeSearch, слова в названиях окон, ИИ-фильтр экрана |
| Установка программ, терминал, USB, свои браузеры | запрещено | **без ограничений** |
| Игры (мини-игры на сайтах, игровые программы) | **запрещены**, тумблер в панели администратора | **разрешены** (закрыто только 18+) |

Установка редакции для учителей на Windows: запустите `SchoolShield-Setup-<версия>.exe`, выберите «Компьютер учителя» (тихо: `SchoolShield-Setup-<версия>.exe /S /edition=teacher`). Фильтр 18+ включается сразу, значок «Центр учителя» появляется на рабочем столе, охрана окон стартует при входе в Windows и живёт в области уведомлений. Управление: Пуск → «SchoolShield» (потребуются права администратора). Редакция запоминается в `config.json` и сохраняется при обновлениях.

Планы: [собственная школьная ОС на Linux](docs/OS-PLAN.md) и [сисадмин-флешка: набор программ и ОС](docs/SYSADMIN-USB.md).

## Быстрый старт

1. Скачайте `SchoolShield-Setup-<версия>.exe` со страницы [Releases](https://github.com/Scrymez/SchoolShield/releases/latest) и запустите (потребуются права администратора).
2. Установщик копирует программу в `C:\Program Files\SchoolShield` и создаёт значок **SchoolShield** на рабочем столе. Защита ещё **не включена**.
3. Откройте значок на рабочем столе — запустится **мастер первого запуска**: код администратора, горячая клавиша, имя ученика, DNS-фильтр, режим интернета, флешки, ИИ-фильтр.
   Для пробы отметьте «Пробный режим» (оболочка Windows не меняется).
4. Перезагрузите компьютер. Он войдёт под учеником и откроет лаунчер.

Тихая установка для администраторов: `SchoolShield-Setup-2.0.0.exe /S` (`/nomodel`, `/noicon`). Удаление: «Установка и удаление программ» или `SchoolShield-Setup.exe /uninstall`.

Требуется Windows 10 Pro / Education / Enterprise (на Home защита от запуска не действует, остальное работает), .NET Framework 4.8 (встроен в Windows 10 с 1903), у администратора Windows должен быть **пароль**.

## Игры: тумблер и исключения

* **Вкладка «Состояние» → «Разрешить игры» / «Запретить игры».** Строка «Игры» показывает текущее состояние. Лаунчер подхватывает переключение за несколько секунд, перезагрузка не нужна; политики Chrome, Edge и Firefox обновляются сразу (скрипт запускается сам).
* **Вкладка «Настройки» → «Игры»:** то же переключение и список **исключений**: сайты игр, которые открываются даже при запрете (по одному в строке, домен или `домен/путь`), например `education.minecraft.net` для урока в Minecraft Education или `yandex.ru/games/app/12345` для одной конкретной игры.
* При запрете: страницы и вложенные окна игровых сайтов блокируются во встроенном браузере; в Chrome, Edge и Firefox действуют политики (Яндекс Игры стоят в списке первыми, чтобы всегда помещаться в лимит политик); окна с заголовками вроде «Яндекс Игры», «Poki — Play free online games», «Unblocked Games» закрываются; процессы Steam, Epic Games, Roblox, Minecraft и т. п. завершаются; такие программы пропадают из раздела «Программы».
* Свои игровые сайты добавляйте в `blocklist.txt` (закрыты всегда) или в `C:\ProgramData\SchoolShield\games.txt` (закрыты, пока игры запрещены). Редакция «Учитель» игры не ограничивает.

## Вход администратора

1. **Зажмите** Ctrl+Shift+Alt+A на 1,5 с (или 7 раз быстро нажмите на часы вверху) — откроется терминал. Пока клавиши удерживаются, виден индикатор.
2. Введите код. После 5 ошибок — блокировка на минуту, всё пишется в журнал.

| Команда | Что делает |
|---|---|
| `explorer` | настоящий рабочий стол Windows (админ-режим на 30 мин) |
| `lock` / `unlock [мин]` | вернуть защиту / снять ограничения клавиш, сворачивания и охраны |
| `sudo <программа>` | запуск от администратора Windows (запросит его пароль) |
| `uninstall [имя]` | удалить программу из Windows полностью |
| `emptybin` | очистить корзину |
| `update` | проверить и установить обновление с GitHub |
| `panel` | панель администратора |
| `config`, `badwords`, `passwd` | править настройки, список слов, сменить код |
| `apps`, `reload`, `status`, `logs [N]` | список программ, обновить, состояние, журнал |
| `logoff`, `restart`, `shutdown`, `exit` | выход на экран входа, перезагрузка, выключение, закрыть |

### Если войти в админку не получается

1. Нажмите **Ctrl+Alt+Del** → «Выход» → на экране входа выберите учётную запись **администратора Windows** (пароль у вас). Откроется обычный рабочий стол со значком SchoolShield: это панель администратора.
2. На ноутбуках клавиши F1–F12 часто работают как функции Fn; поэтому по умолчанию используется буква **A**, а не F12. Если у вас старая комбинация, она тоже продолжает работать.
3. Ничего не помогло: загрузитесь с установочной флешки Windows и создайте файл-выключатель (см. «Аварийное восстановление»).

## Панель администратора

Значок на рабочем столе открывает панель (при открытии она сама докачивает недостающее для ИИ и браузера): состояние защиты (включить / отключить / применить заново), программы (раздел, показывать ученикам, удалить из системы), списки сайтов и слов, ИИ-фильтр (установка модели, порог, проверка картинки), обновления, настройки (заголовок, горячая клавиша, разделы, звонки, общие папки), журнал.

## Обновления

Репозиторий публикует релизы `v<версия>` с файлами `SchoolShield-Setup-<версия>.exe` и `.sig`. Программа проверяет `releases/latest`, скачивает установщик и сверяет подпись с публичным ключом, вшитым в программу (`src/Shared/UpdateKey.cs`). Приватный ключ хранится у автора, не в репозитории. Файл без верной подписи не запускается.

## Аварийное восстановление

Если после включения защиты чёрный экран или нельзя войти:

1. На экране входа выберите учётную запись **администратора**: ей лаунчер открывает обычный рабочий стол. Дальше — «Отключить защиту» в панели или удаление программы.
2. Загрузитесь с установочной флешки Windows → Shift+F10 и создайте файл-выключатель (буква диска может быть другой):
   ```
   type nul > D:\ProgramData\SchoolShield\DISABLE
   ```
   Лаунчер начнёт открывать всем обычный рабочий стол.
3. Или верните оболочку вручную:
   ```
   reg load HKLM\X D:\Windows\System32\config\SOFTWARE
   reg add "HKLM\X\Microsoft\Windows NT\CurrentVersion\Winlogon" /v Shell /t REG_SZ /d explorer.exe /f
   reg unload HKLM\X
   ```

## Ограничения (честно)

- **Блюр рекламы работает только во встроенном браузере.** В других браузерах (если вы их разрешили) блюра нет, действуют DNS-фильтр AdGuard и политики. Скрипт распознаёт рекламу по признакам, а не «обучен» на размеченной выборке: единичные рекламные блоки могут пройти, обычные блоки в редких случаях могут размыться.
- **Окна «Сохранить как» принадлежат самим программам**, поэтому полностью перерисовать их в стиле лаунчера нельзя: включены тёмная тема Windows и тёмный заголовок, но ограничены только возможности окна.
- **Фильтры не абсолютные.** DNS блокирует известные сайты, слова в заголовках ловят очевидное, ИИ-фильтр иногда ошибается (порог настраивается). Самый надёжный режим — «только разрешённые сайты» (`WebMode = Whitelist`).
- **Код администратора** хранится как хэш (PBKDF2, 100 000 итераций) в файле, который ученик теоретически может прочитать. Берите код из 8+ символов.
- **Политики и DNS действуют на всю машину**, в том числе в браузере администратора.
- **Физический доступ**: поставьте пароль на BIOS/UEFI, отключите загрузку с USB, включите BitLocker.
- **Игры и программы в `Program Files`** ученик запустить может. Скрывайте их в панели («Программы») или не ставьте.
- Ctrl+Alt+Del перехватить нельзя; диспетчер задач и смена пароля там отключены.
- Установщик не подписан сертификатом издателя, поэтому SmartScreen и антивирусы могут предупреждать. Для проверки сравните SHA-256 с файлом `.sha256` в релизе.

## Сборка из исходников

```
tools/build.sh            # .NET SDK 6+, zip, openssl (для подписи): dist/SchoolShield-Setup-<версия>.exe
```

Структура: `src/SchoolShield` (лаунчер, браузер, панель, терминал), `src/Setup` (установщик), `src/Shared`, `scripts` (PowerShell: политики, DNS, брандмауэр, учётная запись), `config` (настройки и бан-листы), `assets/adblur.js` (блюр рекламы), `tools/update-blocklists.py` (пересборка бан-листов).
